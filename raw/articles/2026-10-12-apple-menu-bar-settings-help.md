# 摘要筆記

- 路徑：Apple menu > System Settings > **Menu Bar**（Tahoe 起獨立為 Menu Bar 設定；Sequoia 以前為 Control Center 設定頁，網址 slug 仍為 change-control-center-settings 的舊版）。
- 一般：Automatically hide and show the menu bar（Always / On Desktop Only / In Full Screen Only / Never）；**Show menu bar background**（顯示桌布或選單列背景 → 即 Tahoe 的透明選單列開關）；Recent documents 數量。
- **Menu Bar Controls**：Clock（固定顯示）、Siri、Spotlight、Wi-Fi、Bluetooth、Battery（筆電）、Focus、Screen Mirroring、Display、Sound、Now Playing（Show When Active / Always Show）、Fast User Switching、Time Machine、VPN、Weather。
- **Allow in the Menu Bar**：「Some apps provide menu bar items」——逐一勾選是否顯示該 App 的項目（per-app toggle）。
- Reset Control Center。
- 可在自訂 Control Center 時把 controls 直接拖到選單列。
- 頁面未提 overflow、⌘-drag 排序。
